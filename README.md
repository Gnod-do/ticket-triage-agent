# Intelligence Cup 2026 · кейс «Газпром нефти»

**ИИ-агент для ретрансляции обращений в поддержку** — проверенные сигналы из техподдержки в продуктовые команды без дополнительной нагрузки на поддержку.

Ветка `main` содержит только файлы для сдачи. Исходный код прототипа, тесты, спецификации и скрипты сборки — в ветке [`dev`](https://github.com/Gnod-do/ticket-triage-agent/tree/dev).

## Файлы для сдачи (`dist/`)

| Файл | Что это | Требование кейса |
|---|---|---|
| `Решение_Q1-4_Q6.docx` / `.pdf` | Основное решение, вопросы 1–4 и 6 (14,7 тыс. знаков) | docx/doc/pdf, ≤ 15 000 знаков |
| `Q5_Эффект_внедрения.md` | Вопрос 5 — метрики эффекта внедрения | отдельный .md |
| `Презентация.pptx` / `.pdf` | 10 слайдов | ~10 слайдов |
| `AI_Footnotes.md` | Использование ИИ при подготовке | опционально |
| `charts/` | Графики финансовой модели, использованные в документе и слайдах | — |

## Где смотреть код

В ветке `dev`:

- `demo/` — прототип (Qwen через Ollama, кластеризация, агент с инструментами, PolicyGate, оценка на holdout, финансовая модель), 88 офлайн-тестов;
- `submissions/` — исходный текст решения в Markdown;
- `docs/diagrams/` — схемы и скрипты их отрисовки;
- `scripts/build_submission.py`, `scripts/build_slides.py` — сборка DOCX и презентации из исходников.

```bash
git checkout dev
python -m venv .venv && .venv/bin/pip install -e demo
.venv/bin/pytest
python scripts/build_submission.py --pdf && python scripts/build_slides.py --pdf
```
